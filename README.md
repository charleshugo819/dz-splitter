# 地市拆分工具 (dz-splitter)

上传一个 Excel 表格，自动识别「地市」列与表头，按地市拆分成多份新表格：
每份保留表头 + 对应地市的数据行，文件名 = 源文件名-地市名称，打包为 ZIP 下载。

## 使用

1. 打开 `index.html`（或 GitHub Pages 链接）。
2. 上传 `.xlsx / .xlsm` 表格。
3. 确认识别出的「工作表 / 地市列 / 表头行数」，可手动调整。
4. 点击「拆分并下载 ZIP」。

## 说明

- 纯前端实现，直接改写 xlsx 内部 XML，完整保留表头、合并单元格、样式与公式，并同步更新筛选区。
- 依赖 `libs/xlsx.full.min.js`、`libs/jszip.min.js`（本地引用，无需联网）。
- 仅支持 `.xlsx / .xlsm`。
